# Flutter User List (Laravel API)

A simple Flutter app that fetches and displays users from a Laravel backend.

## Requirements
- Flutter >= 3.16.0
- Dart >= 3.2.0
- Laravel backend running on `http://127.0.0.1:8000/api/users`

## How to Run

1. Clone the project
2. Run `flutter pub get`
3. Make sure your Laravel API is running and accessible
   - Android Emulator: use `http://10.0.2.2:8000/api`
   - Physical device: replace with your host machine IP
4. Run with: `flutter run`
